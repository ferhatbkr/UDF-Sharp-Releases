UDF# Privacy Policy

Last updated: September 21, 2026

UDF# is a Windows desktop utility application. This policy explains how the application handles personal data.

1. Data collection

UDF# does not require a user account, does not display advertisements, and does not use an analytics or tracking system for the purpose of collecting personal information about application usage.

UDF# does not send user files, document contents, or personal information to a server controlled by the developer.

2. Documents and local processing

UDF# processes files such as DOC, DOCX, RTF, UDF, PDF, and EYP on the user's computer. Operations such as conversion, text replacement, and EYP extraction are performed locally.

The user is responsible for the contents of files processed with the application. Backing up important documents before processing is recommended.

3. Internet connectivity

The core document-processing functions of UDF# do not require an online account or cloud storage service. If a future version introduces an online feature, the relevant data processing will be disclosed separately within the application.

4. Third-party services

UDF# does not sell or rent personal data to third parties for advertising or analytics purposes. UDF# is not responsible for the data-processing practices of the operating system, antivirus software, cloud-storage service, or other third-party software used by the user.

5. Children's privacy

UDF# is not designed to collect personal information from children or to target a particular age group for data collection.

6. Changes to this policy

This privacy policy may be updated if the application's functionality or data-processing practices change. The current version will be published on this page.

7. Contact

For privacy questions or requests concerning UDF#, please use the GitHub repository.
